# Heart Disease Prediction System Using Machine Learning

## 1. Project Title

**Heart Disease Prediction System Using Machine Learning and Web-Based Clinical Dashboard**

---

# 2. Abstract

Heart disease is one of the leading causes of death worldwide. Early prediction of cardiovascular diseases can significantly improve patient care by enabling timely diagnosis and treatment. This project presents a web-based Heart Disease Prediction System that utilizes Machine Learning to estimate the likelihood of heart disease based on various clinical parameters.

The application combines a trained Random Forest Machine Learning model with a lightweight Python backend and an interactive web interface. Users enter patient information such as age, cholesterol level, blood pressure, chest pain type, ECG results, and other medical indicators. The trained model analyzes these features and predicts the probability of heart disease while classifying the patient into Low Risk, Moderate Risk, or High Risk categories.

The application also stores previous prediction records in a SQLite database, allowing users to review recent assessments. The overall system demonstrates the practical integration of Artificial Intelligence, Machine Learning, Backend Development, Database Management, and Frontend Web Technologies into a single healthcare application.

# 3. Introduction

Heart disease remains one of the most serious health challenges globally. Traditional diagnosis often requires multiple laboratory tests and expert medical analysis. The system is designed primarily for educational purposes and demonstrates how Machine Learning can be integrated into modern healthcare applications.

# 6. Dataset Used

The project uses the **Heart Disease Dataset** obtained from the **UCI Machine Learning Repository**.

The dataset contains several medical attributes collected from patients.

### Important Features

* Age
* Sex
* Chest Pain Type (CP)
* Resting Blood Pressure
* Cholesterol
* Fasting Blood Sugar
* Resting ECG
* Maximum Heart Rate
* Exercise Induced Angina
* Oldpeak
* Slope
* Number of Major Vessels (CA)
* Thalassemia
* Target (Heart Disease)

The target variable is converted into a binary classification problem:

* **0 → No Heart Disease**
* **1 → Heart Disease**

# 7. Machine Learning Model

The prediction model is developed using the **Random Forest Classifier**.

### Why Random Forest?

Random Forest is selected because:

* High prediction accuracy
* Handles missing values effectively
* Reduces overfitting
* Works well with medical datasets
* Robust against noisy data
* Provides probability estimates

---

# 8. Model Training Process

The model training process consists of the following steps:

### Step 1

Load the Heart Disease Dataset from the UCI Repository.

### Step 2

Separate the dataset into:

* Features (X)
* Target (Y)

### Step 3

Split the dataset:

* 80% Training Data
* 20% Testing Data

### Step 4

Build a preprocessing pipeline consisting of:

* Missing value imputation using median values
* Feature standardization
* Random Forest classifier

### Step 5

Train the model.

### Step 6

Evaluate the model using prediction accuracy.

### Step 7

Save the trained model using Joblib.

### Step 8

Store feature order and model metadata in a JSON file.

# 10. Working of the System

## Step 1

The user opens the Heart Disease Prediction webpage.

## Step 2

Patient information is entered into the prediction form.

The system collects medical details including:

* Age
* Gender
* Blood Pressure
* Cholesterol
* Chest Pain Type
* ECG Result
* Heart Rate
* Exercise Angina
* Oldpeak
* Thalassemia

## Step 3

The JavaScript application converts all form values into JSON format.

## Step 4

The JSON data is sent to the Python backend using a POST request.

```
POST /api/predict
```

## Step 5

The backend receives the patient information.

## Step 6

The trained Machine Learning model is loaded using Joblib.

## Step 7

The patient information is converted into a Pandas DataFrame.

## Step 8

The feature order is matched with the order used during training.

## Step 9

The Random Forest model predicts:

* Disease Class
* Probability Score

## Step 10

The probability is converted into a percentage called the Risk Score.

Example:

```
Probability = 0.81

Risk Score = 81%
```

## Step 11

The system assigns a prediction label.

### Low Risk

Prediction = 0

### Moderate Risk

Prediction = 1 and Risk Score below 60%

### High Risk

Prediction = 1 and Risk Score greater than or equal to 60%

## Step 12

The prediction is stored inside the SQLite database.

Saved information includes:

* Patient data
* Risk score
* Prediction label
* Timestamp

## Step 13

The backend returns the prediction to the frontend.

Example response:

```
{
    "risk_score": 82,
    "label": "High risk"
}
```

## Step 14

The webpage immediately updates and displays:

* Risk Percentage
* Risk Category
* Recent Prediction History

# 11. Backend Implementation

Major API Endpoints:

## POST /api/predict

Receives patient information and returns prediction.

## GET /api/history

Returns the latest prediction history.

Supports Cross-Origin Resource Sharing (CORS).

The backend also performs:

* Model loading
* Prediction generation
